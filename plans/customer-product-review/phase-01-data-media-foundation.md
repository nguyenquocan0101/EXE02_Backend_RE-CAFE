# Phase 01 — Data and media foundation

## Objective

Add the relational media model, review navigation/state needed by order mapping, Cloudinary deletion primitives, indexes, and an EF migration without changing public behavior yet.

## Files to create

- Backend `Models/ReviewMedia.cs`
- Backend migration generated by EF, named with the repository's current timestamp convention, e.g. `Migrations/<timestamp>_AddReviewMediaAndReviewIndexes.cs` plus its designer file.

## Files to modify

- `Models/Review.cs` — add `ICollection<ReviewMedia> Media`.
- `Models/Order.cs` — add an optional `ICollection<Review> Reviews` navigation if order DTO mapping uses eager-loaded reviews.
- `Data/ApplicationDbContext.cs` — register `ReviewMedia`; configure required Review FK with cascade delete; add unique `(UserId, OrderId, ProductId)` and public-read `(ProductId, IsVisible, CreatedAt)` indexes.
- `Interfaces/ICloudinaryService.cs` — add deletion methods that accept public ID and resource type/image-vs-video semantics.
- `Services/CloudinaryService.cs` — implement safe image/video deletion and return/log failure information without deleting unrelated assets.

## Implementation notes

1. Run a read-only duplicate check on `Reviews` before applying the unique index. The query must group by `UserId`, `OrderId`, and `ProductId` and report groups with count > 1.
2. Keep `ReviewMedia.PublicId` required; `Url` and `MediaType` should be bounded strings with explicit max lengths.
3. Use `DeleteBehavior.Cascade` only from Review to ReviewMedia. Preserve the existing restrictive Review FKs to User/Product/Order.
4. Generate the migration from the backend project; do not hand-edit the model snapshot except through EF output.
5. Confirm the generated migration does not recreate the existing Reviews table.

## Verification

- `dotnet build` succeeds.
- Generated migration contains only ReviewMedia, the new indexes, and FK changes expected by this phase.
- Disposable database apply succeeds and the unique index exists.
- Deleting a Review cascades to ReviewMedia at the database level.
